# 情境感知智能提醒

## 使用场景

当用户询问天气风险、交通风险、日程冲突、账单截止、是否来得及、是否需要提前预警，或者要求检查未来几天安排风险时，使用 `smart_reminder` 工具。

## 工具规则

- 天气和路线风险必须来自 `smart_reminder` 或真实工具结果，不要凭空判断。
- `smart_reminder(action="check_risks")` 用于检查未来天气、交通、账单和日程风险。
- `smart_reminder(action="route_risk")` 用于评估两个地点之间的高德路线耗时。
- 智能提醒只给预警和建议，不自动修改飞书日历。
- 用户明确要求改期或写入日历时，继续使用 `calendar` 或 `life_event` 完成真实操作。

## 输出要求

- 明确说明事件、风险、依据和建议。
- 高德 API 失败时说明无法确认，不要编造天气或路线。
- 背景巡检使用配置的通知渠道；聊天触发时回复当前渠道。

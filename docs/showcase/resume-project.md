# Copala｜主动式个人智能 Agent

基于 nanobot 的 Channel、Provider 与 Tool Loop 基座进行二次开发，重点新增混合长期记忆、分层决策、主动事件闭环、多源规划和运行时技能沉淀，将通用工具型助手升级为能够记忆、判断、执行并复用经验的个人 Agent。技术栈：Python、asyncio、SQLite/FTS5、RRF、LLM Tool Calling、Cron/Heartbeat、飞书日历、高德与 Web Search。

- **双路决策**：重构 AgentLoop 为“领域终止型快路径 → LifeEvent 条件预处理 → LLM+Tools 慢路径”，覆盖 6 类意图；60 条未参与调优的留出指令准确率与 Macro-F1 均为 100%，通用请求误拦截率为 0%，40/40 个快路径请求零模型调用，在确定性执行与长尾泛化间建立可测量边界。
- **混合记忆**：在 nanobot 会话摘要上新增 SQLite FTS5/BM25、192 维本地 signed-hash 向量与 RRF 融合检索；200 条记忆、30 条留出查询上 Recall@5 90.00%、MRR@5 0.711、nDCG@5 0.760，10,000 条本地记忆下 P50/P95 中位数为 649.66/691.75 ms，实现无需外部 Embedding 服务的跨轮个性化召回。
- **主动闭环**：在 nanobot Cron/Heartbeat 主动触发基座上新增 LifeEvent 处理链，从聊天、邮件和日历巡检中抽取事件类型、时间与地点，联动日历、TODO、Cron、RAG 和通知，并按来源幂等去重；48 条留出样本检测 F1 98.63%，字段准确率均为 100%，20/20 组重复输入被抑制，使 Agent 从“理解信息”推进到“产生行动”。
- **韧性规划**：将通用工具调用扩展为记忆、日历、高德路线/天气与 Web Search 的多源编排，通过确定性模板与局部降级契约生成可执行计划；40 个故障注入场景计划生成 40/40 成功，其中外部依赖失败场景 32/32 成功降级、必要信息覆盖率 100%，30 条天气/交通/账单样本风险识别 F1 为 100%。
- **技能生长**：在 nanobot Skills 基座上新增 LearnSkillTool，将任务解法沉淀为脚本与 `SKILL.md` 并支持后续重新发现、执行；加入路径隔离、敏感信息提示和覆盖保护，保存—发现—复用及安全场景 30/30 通过；完整测试 282/282 通过，新增核心模块行/分支覆盖率为 79.02%/61.22%，使能力增长可复现、可审计。
